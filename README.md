# BantAI v2 — public works, read closely

A weekly, open-data screen of DPWH public works contracts in the Philippines: https://aldiar523.github.io/bantai-v2/

Every Monday the full DPWH project list is read and open contracts are marked for a closer look:
**A** official record · **B** a rule is broken · **C** several independent signals at once.
A mark is a request to check, never an accusation. Private individuals are not named.

This repository holds only the built pages and public data. Marks B and C and reviewer material are encrypted
(`data/reviewer.enc.json`) and open only with the review team's key. Each weekly list is sealed with a SHA-256
fingerprint (see the ledger page). A capstone project, Lee Kuan Yew School of Public Policy.
