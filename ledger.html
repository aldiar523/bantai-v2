Sealed lists

Weekly ledger

Each Monday's list gets a digital seal: a code calculated from every entry in the list. If anyone changes even one entry, the seal breaks. Seals are saved in a public history, so a list can later be compared with audits, cases and statements that come out.

Check a file's seal

Choose a downloaded CSV file. Your browser calculates its seal and compares it with this ledger. The file is not sent anywhere. The seal protects the CSV; a PDF is a readable copy.

For technical readers: the digital seal is a SHA-256 hash of the CSV file, byte for byte. Two lists with the same seal are identical.
