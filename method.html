How BantAI works

Every week, 266,890 public works contracts. Which ones should someone check?

BantAI reads the whole DPWH project list each Monday and marks the open contracts that auditors, reporters and citizen monitors should look at first, with the reason and the source for each mark.

A mark is a request to check. It is never a finding, and it never says that anyone did wrong.

Honest limits

What it can do, and what it cannot

It can

  • Read all 266,890 contracts in the DPWH list every week.
  • Show which open contracts already carry an official record.
  • Find figures that break a rule.
  • Show where several independent warning signs agree.
  • Seal each week's list, so it can be tested later.

It cannot

  • Say whether a contract is corrupt, or how likely it is.
  • See payments, the site itself, or private agreements.
  • Prove yet that its warning signs predict wrongdoing.
  • Correct DPWH's statuses, dates or locations.
  • Replace a site visit or a document check.

Six steps, the same each week

Save the full DPWH list and what changed since last week.

02

Join

03

Check

Run every check on every open contract. Contracts reported 100% done count as complete.

04

Rank

A, then B, then C; larger first; no office above 30% of the top 50.

05

Seal

Fix the list with a fingerprint in the public ledger.

06

Review

People read the documents, may ask for an AI review, and decide.

AI review

A second look, on request

A reviewer can ask for an AI review of one contract: a summary, ordinary explanations to rule out, what news, official statements and court records say, and the next documents to request. Every outside claim links to its source.

It advises. It never changes a mark or a decision, never calls anyone corrupt, and only the review team sees it.
